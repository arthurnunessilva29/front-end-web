# Projeto 2 - Interface Express

**Tema:** Portal Front-End — apresentação de conteúdos introdutórios de HTML, CSS e formulários.

## Como abrir
1. Extraia o arquivo ZIP.
2. Abra a pasta `projeto2_interface_express` no VS Code.
3. Abra `index.html` no navegador ou use a extensão Live Server.

## Prompts principais utilizados
- “Gere uma estrutura HTML simples para uma landing page, sem JavaScript, sobre conteúdos de Front-End.”
- “Explique as propriedades CSS e adicione comentários para facilitar o entendimento.”
- “Adapte o CSS para organizar cards, destacar foco e funcionar em telas menores.”

## Três propriedades pesquisadas
- `box-shadow`: adiciona sombra aos cards.
- `linear-gradient()`: cria uma transição gradual entre cores no cabeçalho.
- `outline`: desenha um contorno ao redor do campo ou link que está em foco.

## Propriedades mantidas na versão final
- `box-shadow`: foi mantida nos cards para destacá-los do fundo sem usar bordas muito fortes.
- `linear-gradient()`: foi mantida no cabeçalho para combinar dois tons de azul.

Também foi mantido `outline` para ajudar a identificar o elemento selecionado, especialmente ao navegar com o teclado.

## Observação
O formulário é demonstrativo e não envia os dados para um servidor. O HTML e o CSS foram adaptados a partir do exemplo fornecido na aula. Revise os textos e substitua o campo de integrantes antes da entrega.
