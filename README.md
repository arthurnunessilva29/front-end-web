# 🌐 Desenvolvimento Front-End para Web

Repositório destinado ao armazenamento de atividades, exercícios, exemplos de código e conteúdos desenvolvidos durante a disciplina **Desenvolvimento Front-End para Web**, ministrada pelo professor **Vinicius Alves**, no 2º semestre de 2026.

O objetivo da disciplina é compreender o funcionamento da web e aprender a desenvolver páginas utilizando HTML, CSS e JavaScript, explorando desde a criação da estrutura até a estilização e funcionalidades dos sites.

## 🎯 Objetivo da disciplina

O desenvolvimento front-end é responsável pela parte visual e interativa de um site, ou seja, tudo aquilo que o usuário consegue visualizar e utilizar diretamente no navegador.

Durante as aulas, são estudadas as principais tecnologias utilizadas nesse desenvolvimento:

| Tecnologia | Função |
|---|---|
| HTML | Organizar os elementos e conteúdos da página |
| CSS | Definir estilos, cores, espaçamentos e layouts |
| JavaScript | Adicionar funcionalidades, lógica e interatividade |

## 📚 Conteúdos abordados

- Fundamentos da internet e funcionamento da web
- Protocolos HTTP e HTTPS
- Modelo cliente e servidor
- URLs, domínios e DNS
- Introdução e estrutura do HTML5
- Tags, atributos e elementos semânticos
- Criação de links, imagens, listas e tabelas
- Formulários e validação de dados
- Inserção de áudio e vídeo em páginas
- Fundamentos de CSS e seletores
- Classes, IDs e organização dos elementos
- Box Model, bordas, margens e espaçamentos
- Flexbox e CSS Grid
- Introdução à linguagem JavaScript
- Variáveis, operadores e tipos de dados
- Estruturas condicionais e de repetição
- Funções e arrow functions
- DOM e manipulação de elementos
- Eventos e interação com o usuário

## 🧱 HTML — Estrutura das páginas

O HTML é utilizado para definir a organização e os elementos de uma página web. Nesta etapa, são trabalhados conceitos como:

- Estrutura inicial de um documento HTML.
- Títulos, parágrafos e listas.
- Links e imagens.
- Tabelas e formulários.
- Tags semânticas, como `header`, `main`, `section`, `nav` e `footer`.
- Atributos e referências de arquivos.
- Boas práticas de organização e acessibilidade.

## 🎨 CSS — Estilização e layout

O CSS permite modificar a aparência dos elementos criados com HTML, deixando as páginas mais organizadas e agradáveis visualmente.

Principais assuntos estudados:

- Aplicação de CSS externo, interno e inline.
- Seletores de elementos, classes e IDs.
- Cores, fontes e propriedades de texto.
- Margens, padding, bordas e dimensões.
- Box Model.
- Sombras e arredondamento de elementos.
- Flexbox para alinhamentos e organização.
- Grid para criação de layouts.
- Responsividade e efeitos de interação.

## ⚙️ JavaScript — Lógica e interatividade

JavaScript é utilizado para fazer com que as páginas respondam às ações do usuário e executem diferentes funcionalidades.

Conteúdos estudados:

- Declaração de variáveis com `var`, `let` e `const`.
- Tipos de dados e conversões.
- Operadores aritméticos, relacionais e lógicos.
- Estruturas condicionais (`if`, `else` e `switch`).
- Estruturas de repetição (`for`, `while` e `do...while`).
- Criação e utilização de funções.
- Arrow functions.
- Manipulação de elementos HTML pelo DOM.
- Eventos de clique, teclado e formulário.
- Alteração de conteúdos e estilos através do JavaScript.

## 🧭 Evolução do aprendizado

O aprendizado está dividido em etapas, começando pelos conceitos fundamentais de como a internet e os sites funcionam, avançando para a construção de páginas e, posteriormente, para a criação de layouts e funcionalidades.

A proposta é utilizar os conhecimentos adquiridos nas aulas para desenvolver pequenos projetos e praticar a integração entre as três tecnologias.

## 💻 Como acessar os arquivos

Para visualizar os exercícios e projetos deste repositório:

1. Faça o download ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Localize o arquivo HTML que deseja visualizar.
4. Abra o arquivo no navegador.
5. Utilize o modo de desenvolvedor (`F12`) para analisar os elementos, estilos e possíveis erros no código.

Alguns projetos que utilizam funcionalidades de servidor, como PHP, podem precisar de um ambiente local para funcionar corretamente.
